# حياة المواطن – Hayat Al Mouwatin (Demo)

Front-end prototype of a Mauritanian news website (Arabic RTL / French LTR).

- Single static file: `index.html` (no build step, no server)
- Pages via hash routes: `#home`, `#n-<id>` (article), `#c-<category>`, `#admin`
- Demo admin: any username/password. Data is stored in the browser's LocalStorage only (no backend or database).
- Images are generated placeholders; replace with real photos in production.

## Run
Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
